## Hi there 👋

Hi! I'm Johanna, a 22 year old Business Informatics student based in Cluj-Napoca, Romania, with a passion for web development and UI/UX design.

My interest in web development started with a simple curiosity about how websites are designed and built. I've always been drawn to the way thoughtful layouts, colors, and interactive elements come together to create engaging digital experiences. Over time, that curiosity grew into a genuine passion for technology and creative problem-solving.

I'm expanding my skills toward full-stack development, building on my foundation HTML, CSS, JavaScript, and React, currently expanding my expertise in modern web technologies, including Next.js, TypeScript, Node.js, and PostgreSQL. I'm passionate about creating modern, responsive web applications and developing a deeper understanding of both front-end and back-end development, with a focus on writing clean, maintainable code and delivering intuitive user experiences.
